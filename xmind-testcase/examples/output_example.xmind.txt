文件上传流程
├─ 1. 主流程
│  ├─ TC-UPLOAD-001 上传流程_列表页点击上传按钮_进入上传页_显示空表单
│  │  ├─ 操作步骤 1：打开文件列表页
│  │  ├─ 操作步骤 2：点击上传按钮
│  │  └─ 预期结果：进入上传页并显示空表单
│  ├─ TC-UPLOAD-002 上传流程_上传页选择文件_点击下一步_进入确认页
│  │  ├─ 操作步骤 1：在上传页选择一个有效文件
│  │  ├─ 操作步骤 2：点击下一步按钮
│  │  └─ 预期结果：进入确认页并显示待上传文件信息
│  └─ TC-UPLOAD-003 上传流程_确认页点击确认上传_上传完成_显示成功结果
│     ├─ 操作步骤 1：在确认页核对文件信息
│     ├─ 操作步骤 2：点击确认上传按钮
│     └─ 预期结果：进入结果页并显示上传成功提示
├─ 2. 流程中断
│  ├─ TC-UPLOAD-004 上传流程_上传页点击取消_返回列表页_文件未上传
│  │  ├─ 操作步骤 1：进入文件上传页
│  │  ├─ 操作步骤 2：点击取消按钮
│  │  └─ 预期结果：返回文件列表页且没有新增上传记录
│  └─ TC-UPLOAD-005 上传流程_确认页点击返回_返回上传页_已选文件保留
│     ├─ 操作步骤 1：完成文件选择并进入确认页
│     ├─ 操作步骤 2：点击返回按钮
│     └─ 预期结果：返回上传页且已选文件信息保留
├─ 3. 页面跳转异常
│  └─ TC-UPLOAD-006 上传流程_直接访问确认页URL_无文件上下文_提示重新选择文件
│     ├─ 操作步骤 1：未选择文件时直接访问确认页 URL
│     └─ 预期结果：系统提示重新选择文件或返回上传页
├─ 4. 状态与数据一致性
│  └─ TC-UPLOAD-007 上传流程_上传成功后返回列表页_刷新列表_新文件出现在列表
│     ├─ 操作步骤 1：完成文件上传
│     ├─ 操作步骤 2：返回文件列表页
│     ├─ 操作步骤 3：刷新列表
│     └─ 预期结果：新上传文件出现在文件列表中
└─ 5. 重复提交并发防重
   └─ TC-UPLOAD-008 上传流程_确认页快速重复点击确认上传_重复提交_只生成一条上传记录
      ├─ 操作步骤 1：进入上传确认页
      ├─ 操作步骤 2：快速多次点击确认上传按钮
      └─ 预期结果：系统只生成一条上传记录
